✦ Infrastructure

Hosting & Deployment

🌊
DigitalOcean Droplet
Virtual Private Server

This site is self-hosted on a DigitalOcean Droplet — a cloud-based virtual private server running Linux. Rather than using a managed hosting platform, I configured and manage the server environment myself, giving me full control over how the site is deployed and served.

DigitalOcean Linux VPS Self-managed Cloud Hosting
⚙️
Web Server Configuration
Custom server setup

I configured and run my own web server directly on the Droplet — handling routing, serving static files, and managing the server process myself. This means every request to this site goes through infrastructure I set up and maintain from scratch.

Custom Config Static File Serving Manual Setup
🔄
Version Control & Deployment
Git-based workflow

The codebase is version-controlled with Git. Updates are pushed from my local machine and deployed to the server manually, giving me hands-on experience with a real end-to-end deployment workflow.

Git Manual Deploy Version Control

✦ Design & Code

How It's Built

🌸
Frontend
  • Pure HTML, CSS, and vanilla JavaScript — no frameworks or dependencies.
  • Custom CSS variables for a cohesive rose and gold color palette throughout.
  • Google Fonts for typography: Pinyon Script, Cormorant Garamond, and EB Garamond.
  • Scroll-triggered fade-up animations via the Intersection Observer API.
  • Responsive layout adapting gracefully to different screen sizes.
💎
Design Decisions
  • Entirely hand-coded aesthetic — every detail chosen intentionally.
  • Floating pearl animation and decorative ✦ motifs for a romantic, editorial feel.
  • Custom SVG cursor to carry the rose-and-gold theme into the browser itself.
  • Layered radial gradients to create depth and atmosphere without images.
  • Repeating rose-and-gold nav border as a subtle signature detail.
🖥️
Infrastructure
  • Hosted on a DigitalOcean Droplet running Linux.
  • Web server configured and managed from scratch on the VPS.
  • No third-party CMS or managed hosting — full ownership of the stack.
  • Deployed and updated manually via Git.
✨
Why I Built It This Way
  • Wanted hands-on experience owning a real production server.
  • Chose vanilla HTML/CSS to demonstrate foundational web skills.
  • Self-hosting means understanding every layer — from DNS to the browser.
  • A portfolio about CS should itself be a CS project worth talking about.
